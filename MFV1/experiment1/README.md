# Overreaction

Forecasting Task:

https://pennmem.github.io/forcasting_and_memory/

## Files: 

- `consent.html` — Consent page
- `index.html` — Forecasting task
- `original_task.html` — Original forecasting task as designed in Afrouzi et al. (2023)
- `wordpool.js` — Contains the PEERS 1638 word pool as in Kahana et al. (2024)
- `data/` — Downloaded session JSON files; each file named according to its completion code (e.g. `CCD26812C0.json`). Schema in `data/data_schema.md`

To download data, open the task with `?debug=1` added to the URL and can then use the `Download Data` button on the final screen
