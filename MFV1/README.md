# MFV1

Memory and forecasting (overreaction) experiments, Computational Memory Lab, University of Pennsylvania.

- `experiment1/` — the browser-based forecasting task (consent, task, original Afrouzi et al.
  task, PEERS word pool), its session data, and the Experiment 1 results.
- `experiment2/` — the Prolific experiment: Flask server, task code, pilot data (anonymized),
  analysis notebooks, figures, and results. See `experiment2/README.md`.
